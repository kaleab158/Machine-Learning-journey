⚙️ Getting Started
Clone the repository:
bash
   git clone https://github.com/kaleab158/Machine-Learning-journey.git
   cd machine-learning-journey
(Optional) Create a virtual environment:
bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
Install the common dependencies:
bash
   pip install pandas numpy matplotlib scikit-learn ipywidgets notebook
Open a project folder, read its README, and launch the notebook:
bash
   jupyter notebook
